Goal

- Return the exact same bytes when downloading.
- Keep metadata format compatible with frontend:
  extension, mime_type, size_bytes.

STEP 2) UPDATE SERVICE SIGNATURE AND LOGIC (DocumentManageService)
================================================================
Replace your current createDocument(DocumentManage document) flow with:

public DocumentManage createDocument(MultipartFile file, Integer folderId, String title)

What this method must do:
1. Build new DocumentManage.
2. Resolve title:
   - use title if provided
   - else use file.getOriginalFilename()
3. Build extension from original filename.
4. Build metadata map:
   - extension
   - mime_type
   - size_bytes
5. Set binary/file fields:
   - setFileData(file.getBytes())
   - setOriginalFilename(originalFilename)
   - setContentType(mime)
6. If folderId != null, load folder entity and set document folder.
7. Save via repository.

Example implementation:

public DocumentManage createDocument(MultipartFile file, Integer folderId, String title) {
    try {
        DocumentManage document = new DocumentManage();

        String originalFilename = file.getOriginalFilename();
        String resolvedTitle = (title != null && !title.isBlank()) ? title : originalFilename;
        document.setTitle(resolvedTitle);

        String extension = "FILE";
        if (originalFilename != null && originalFilename.contains(".")) {
            extension = originalFilename.substring(originalFilename.lastIndexOf('.') + 1).toUpperCase();
        }

        String mime = file.getContentType() != null ? file.getContentType() : "application/octet-stream";

        document.setMetadata(java.util.Map.of(
                "extension", extension,
                "mime_type", mime,
                "size_bytes", file.getSize()
        ));

        document.setOriginalFilename(originalFilename);
        document.setContentType(mime);
        document.setFileData(file.getBytes());

        if (folderId != null) {
            FolderManager folder = folderManagerRepository.findById(folderId)
                    .orElseThrow(() -> new IllegalArgumentException("Folder not found with id: " + folderId));
            document.setFolder(folder);
        }

        return documentManageRepository.save(document);
    } catch (java.io.IOException e) {
        throw new RuntimeException("Failed to read uploaded file content", e);
    }
}

Notes:
- Inject FolderManagerRepository into this service if you use folder_id.
- Keep moveDocument() only changing folder field.

STEP 4) REPLACE DOWNLOAD PLACEHOLDER ENDPOINT
================================================================
Your current endpoint returns new byte[] {1,2,3}.
Replace with real file bytes and proper headers.

Use this:

@GetMapping("/{id}/download")
public ResponseEntity<byte[]> downloadDocument(@PathVariable Integer id) {
    DocumentManage doc = documentManageService.getDocumentById(id);

    byte[] content = doc.getFileData();
    if (content == null || content.length == 0) {
        throw new IllegalArgumentException("No file content stored for document id: " + id);
    }

    String filename = (doc.getOriginalFilename() != null && !doc.getOriginalFilename().isBlank())
            ? doc.getOriginalFilename()
            : doc.getTitle();

    String contentType = (doc.getContentType() != null && !doc.getContentType().isBlank())
            ? doc.getContentType()
            : "application/octet-stream";

    return ResponseEntity.ok()
            .header("Content-Disposition", "attachment; filename=\"" + filename + "\"")
            .contentType(org.springframework.http.MediaType.parseMediaType(contentType))
            .body(content);
}

================================================================
COMMON PITFALLS
================================================================
1) File downloads empty
- Cause: file_data not saved, or download endpoint still placeholder bytes.

2) SQL jsonb error on metadata
- Cause: metadata mapped as String instead of JSON map.

3) Unauthorized on upload/download
- Cause: missing Authorization: Bearer <token> on protected endpoints.

================================================================
DONE CRITERIA
================================================================
You are done when:
- Upload stores both metadata and binary content.
- Download returns original file bytes.
- Dashboard still shows file size/type correctly.
