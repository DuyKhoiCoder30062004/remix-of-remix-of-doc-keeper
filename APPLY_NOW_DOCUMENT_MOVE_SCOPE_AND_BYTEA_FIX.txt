public DocumentManage moveDocument(Integer id, Integer folderId) {
    if (folderId == null) {
        throw new IllegalArgumentException("folder_id is required");
    }

    DocumentManage existing = getDocumentById(id);
    FolderManager target = folderManagerRepository
            .findById(folderId)
            .orElseThrow(() -> new IllegalArgumentException("Folder not found with id: " + folderId));

    UserManager current = getCurrentUser();

    // Owner-only move policy (adjust if you want admin override)
    if (existing.getOwner() == null || !existing.getOwner().getUserId().equals(current.getUserId())) {
        throw new IllegalArgumentException("You can only move your own documents");
    }

    if (target.getOwner() == null || !target.getOwner().getUserId().equals(current.getUserId())) {
        throw new IllegalArgumentException("You can only move to your own folders");
    }

    existing.setFolder(target);
    return documentManageRepository.save(existing);
}

public List<DocumentManage> getDocuments(Integer folderId, String q) {
    UserManager current = getCurrentUser();
    Integer userId = current.getUserId();

    if (folderId != null) {
        if (q != null && !q.isBlank()) {
            return documentManageRepository
                    .findByOwner_UserIdAndFolder_FolderId(userId, folderId)
                    .stream()
                    .filter(doc -> doc.getTitle() != null && doc.getTitle().toLowerCase().contains(q.toLowerCase()))

public List<DocumentManage> searchDocuments(String q) {
    UserManager current = getCurrentUser();
    Integer userId = current.getUserId();

    if (q == null || q.isBlank()) {
        return documentManageRepository.findByOwner_UserId(userId);
    }

    return documentManageRepository.findByOwner_UserIdAndTitleContainingIgnoreCase(userId, q);
}

H) CLARIFICATION ABOUT getCurrentUser()
================================================================
`getCurrentUser()` is NOT a method inside UserManager entity.
It is a helper method you add inside service classes (for example DocumentManageService and FolderManagerService).

For your current security setup, this exact helper is valid because JwtAuthenticationFilter stores UserManager as principal:

private UserManager getCurrentUser() {
    Authentication auth = SecurityContextHolder.getContext().getAuthentication();
    if (auth == null || !(auth.getPrincipal() instanceof UserManager user)) {
        throw new IllegalArgumentException("Unauthorized");
    }
    return user;
}

Why this works in your codebase:
- In JwtAuthenticationFilter, you build UsernamePasswordAuthenticationToken with principal = user (UserManager object).

Fallback-safe variant (optional):
- If later your principal becomes a String email or UserDetails, load UserManager from UserManagerRepository by email.
